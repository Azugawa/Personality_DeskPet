# 产品目标与开发路线

目标：制作可安装、可个性化配置、可持续升级的桌面宠物软件。先支持 Windows，再评估其他平台。
以下是待实现计划，不表示功能已经交付；不预设发布日期。

## 1. 桌宠体验

- 完善坐下、起身、休息、使用电脑等动作及家具遮挡关系。
- 增加设置界面，保存角色、位置、大小、行为偏好。
- 完善托盘、退出、开机启动选项和透明区域鼠标穿透。
- 验收：重启能恢复用户设置；桌宠不干扰正常桌面操作。

## 2. 个性化资源

- 定义角色包、动画包、家具包的版本化格式。
- 在设置中预览、安装、切换资源，并诊断缺失图片和配置错误。
- 验收：用户无需改源码即可切换角色，异常资源不会导致程序崩溃。

## 3. 安装包与版本发布

- 建立 Godot Windows 导出预设，确定安装器方案及资源授权清单。
- 区分程序目录和用户数据目录；支持安装、升级、卸载及保留设置。
- 建立版本号、变更记录、Git 标签与 GitHub Releases 流程。
- 发布安装包与 SHA-256 校验文件，后续接入构建自动化和代码签名。
- 验收：在干净 Windows 环境完成下载、安装、启动、卸载和覆盖升级。

## 4. 软件更新

- 首先实现手动检查新版本与跳转下载；再实现可选的后台检查。
- 更新元数据包含版本、平台、下载地址、校验值、发行说明和兼容性要求。
- 下载和校验成功后再启动独立更新器；妥善退出主程序并支持失败恢复。
- 用户设置和自定义资源不随程序替换丢失；失败和离线状态不影响现有桌宠运行。
- 验收：测试升级成功、网络中断、校验失败、拒绝更新和旧配置迁移。
