# 版本与国内更新

当前 0.2.0：公开测试版。核心桌宠、托盘、安装器已实现，提醒和对话仍未实现，更新发布链路尚未联调，因此暂不标记 1.0.0。

- 0.2.x：动画、交互和兼容性修复。
- 0.3.0：提醒与用户设置。
- 0.4.0：模型对话。
- 1.0.0：完成目标功能、国内更新和安装升级验证后的稳定版。

国内分发不需要 GitHub 镜像服务。准备一个国内对象存储桶（如腾讯云 COS 或阿里云 OSS）、可公开下载的 HTTPS 地址；是否使用自定义域名/CDN由所选服务配置决定。不需要购买计算服务器。

上传版本目录下的安装 EXE，再上传 update.json。清单的 url 改为该 EXE 的 HTTPS 地址，sha256 保持与实际安装包一致。清单适合短缓存，版本目录下的安装包不要覆盖。

将国内清单完整 URL 放在 config/updates.json 的 feeds 第一项，将安装包目录 URL（以 / 结尾）添加到 allowed_download_prefixes。GitHub 可保留第二项作为备用。重新打包后客户端优先访问国内源。域名应由维护者控制，不使用陌生的第三方代理。

目前没有可用的国内存储账号或域名，配置仍只有 GitHub，不能宣称国内源已上线。部署前需提供公开下载域名与清单地址，不需要把账号密码写进客户端。

0.2.1：GitHub 直连失败后，按 updates.json 中 github_proxy_prefixes 顺序拼接原始链接重试。无效清单、HTTP 错误、超时及安装包校验失败均尝试下一地址。公共代理不代表发行者签名，也不保证长期可用。国内自有源仍可优先配置。
